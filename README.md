# Supermart Grocery Sales Analysis

In this project, I analysed about 10,000 grocery orders (2015 to 2018) from a supermarket in Tamil Nadu using Python (Pandas, Matplotlib, Seaborn).

## Data Cleaning
- No missing values or duplicate rows were found
- Removed the North region because it had only 1 order

## Questions
1. Which categories sell the most and the least?
2. Which regions sell the most and the least?
3. Which 5 cities have the highest sales and profit?
4. Do higher sales lead to higher profit?
5. Do discounts affect profit?
6. Which sub categories sell the most?
7. How did sales change each year in each region?
8. How did profit change each year in each category?

## Findings
1. **Eggs, Meat & Fish** sells the most and **Oil & Masala** sells the least, but the difference is small.
2. **West** has the highest sales and profit. **South** has the lowest.
3. Top cities by sales: **Kanyakumari, Vellore, Bodi, Tirunelveli, Perambalur**. Top cities by profit: **Vellore, Bodi, Kanyakumari, Perambalur, Karur**.
4. Yes. Orders with higher sales usually bring higher profit.
5. No. Discounts are about the same in every region and have almost no effect on profit.
6. **Health Drinks** and **Soft Drinks** sell the most. **Rice** sells the least.
7. Sales grew every year in all regions, with the biggest jump in 2018.
8. Profit grew in every category. **Snacks** made the most profit in 2018, and **Food Grains** grew the fastest.
